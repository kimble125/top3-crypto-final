# Top 3 Crypto AI 이용 고지

시행일: 2026-10-20

Top 3 Crypto(https://top3-crypto.vercel.app)는 생성형 인공지능(AI)을 사용합니다. 이 문서는 어디에 어떤 AI가 쓰이고, 무엇을 보내며, 어떻게 확인하는지 설명합니다.

## 1. 이 서비스는 AI에 기반해 일부가 운영됩니다

- 이 서비스의 일부 결과물은 **OpenAI의 GPT**가 만들고, GPT가 실패하면 **Anthropic의 Claude**가 만듭니다.
- 팀 컴퓨터의 예약 작업이 AI 제공업체의 공식 명령줄 도구(Codex CLI, Claude Code)로 AI를 호출합니다. 이용자가 화면에서 AI에게 직접 질문하는 기능은 없습니다.
- AI가 만든 부분은 'AI 분석' 카드·탭 안에 두고, 추정치에는 'AI 추정'을 붙입니다.

## 2. 화면에서 AI가 만든 부분과 코드가 만든 부분

| 화면 요소 | 누가 만드나 | 표시 |
|---|---|---|
| 분석 글(시장 해설) | AI | 'AI 분석' 카드·탭 안, 쓴 모델 이름 표시 |
| 뉴스 제목별 긍정/중립/부정 라벨 | AI | 'AI 분석' 탭 3절(News Analysis) 안 |
| 'AI 추정' 범위 | AI | "AI 추정" 표시 |
| BTC/ETH/XRP **신뢰도(%)** | **코드가 계산** (AI 아님) | 코드 계산 |
| 지표 차트 수치 | 코드가 계산 | 코드 계산 |
| 공식 매매 트리거 | **코드 조건 + AI 추세 방향이 모두 일치할 때** | 두 조건 일치 시에만 기록 |

## 3. AI에 보내는 것과 보내지 않는 것

**보내는 것 (모두 공개 정보):** 공개 시세 수치(캔들, 지표 값, 공포·탐욕 지수, 미결제약정, 코인베이스 프리미엄)와 GDELT 뉴스 제목. 네이버 뉴스 검색결과는 네이버 검색 API 약관(2026-09-07 시행 특약 2.3)에 따라 AI에 보내지 않는다.

**보내지 않는 것:** 이용자의 접속 기록(IP 등), 이용자가 브라우저에 저장한 설정, 이름·이메일 같은 개인정보. 서비스에는 로그인이 없어 이용자 개인정보가 AI로 갈 길이 없습니다.

참고: 별도 로컬 시제품 알프레도(모의투자, 합성 가격)는 이용자가 입력한 질문을 GPT에 보내지만, 자기 컴퓨터(127.0.0.1)에서만 실행되고 공개 서비스가 아닙니다. 개인정보나 계좌, 금액은 입력하지 말라는 경고가 화면에 있고 대화는 저장하지 않습니다.

## 4. 사람과 코드가 하는 확인

- 신뢰도(%)와 트리거 조건은 사람이 짠 코드로 계산해 AI가 숫자를 바꿀 수 없습니다.
- 트리거는 코드 조건과 AI의 추세 방향이 **둘 다** 맞아야 만들어집니다. 한쪽만 맞으면 만들지 않습니다.
- AI 결과는 화면에 나가기 전에 코드가 매번 검사합니다: 권유 표현, 입력에 없는 숫자, 현재가 ±30% 밖의 추정, 지시문 조각이 있으면 버리고 이전 분석을 씁니다.
- 뉴스 제목에 숨은 지시문(예: "이전 지시를 무시하라")은 AI에 보내기 전에 거릅니다.
- 팀은 운영 화면과 실패 기록을 보며 규칙·프롬프트를 고칩니다(정해진 주기는 없음).

## 5. 한계와 오류

- AI는 틀린 사실이나 오래된 내용을 그럴듯하게 쓸 수 있습니다. 뉴스 라벨(긍정/중립/부정)도 틀릴 수 있습니다.
- 'AI 추정' 범위는 예측이 아니라 참고용 추정입니다.
- 외부 데이터나 AI 제공처 장애로 결과가 늦거나 비어 있을 수 있습니다.
- 이 서비스는 **정보 제공용이며 투자 권유가 아닙니다.** 투자 판단과 책임은 이용자에게 있습니다.

## 6. AI 기본법과의 관계

「인공지능 발전과 신뢰 기반 조성 등에 관한 기본법」(약칭 인공지능기본법)은 **2026년 1월 22일** 시행되었습니다. [시행 2026. 1. 22.] [법률 제21311호, 2026. 1. 20., 일부개정]

제31조(인공지능 투명성 확보 의무)는 다음과 같이 정합니다.

> ① 인공지능사업자는 고영향 인공지능이나 생성형 인공지능을 이용한 제품 또는 서비스를 제공하려는 경우 제품 또는 서비스가 해당 인공지능에 기반하여 운용된다는 사실을 이용자에게 사전에 고지하여야 한다.
>
> ② 인공지능사업자는 생성형 인공지능 또는 이를 이용한 제품 또는 서비스를 제공하는 경우 그 결과물이 생성형 인공지능에 의하여 생성되었다는 사실을 표시하여야 한다.

제2조 제7호 나목은 다른 사업자가 개발한 인공지능을 이용해 제품이나 서비스를 제공하는 자를 "인공지능이용사업자"로 봅니다. 팀은 학생 비영리 프로젝트라서 이 법의 의무 대상인지 분명하지 않지만, 이용자에게 알리는 것이 옳다고 보아 다음과 같이 합니다.

1. 이 문서와 이용약관, 화면 하단 링크로 AI 기반 운영 사실을 **사전에 고지**합니다. 시행령의 확정 조문을 직접 확인하지 못해, 이 고지 방법이 법의 요건을 다 채우는지는 확정하지 않았습니다.
2. 생성형 AI가 만든 글과 라벨은 화면에서 **'AI 분석' 영역과 'AI 추정' 표시**로 구분합니다.
3. 실제와 구분하기 어려운 가상의 음향, 이미지, 영상은 만들지 않습니다.

법률 자문이 아니라 팀의 해석입니다. 세부 이행 방법은 시행령과 과학기술정보통신부 가이드라인이 바뀌면 따라 고칩니다.

## 7. 외부 AI 제공업체

- OpenAI (Codex CLI, ChatGPT 계정): 개인 플랜은 설정에 따라 대화가 모델 개선에 쓰일 수 있고, 끌 수 있습니다. https://help.openai.com/en/articles/5722486-how-your-data-is-used-to-improve-model-performance
- Anthropic (Claude Code, 구독 계정): 계정의 모델 개선 설정에 따라 학습 사용 여부가 정해집니다. https://code.claude.com/docs/en/data-usage
- 팀 계정 설정(2026-10-19 확인): Anthropic '모델 개선'은 꺼져 있다. OpenAI '모델 개선을 위한 데이터 학습 허용'은 10-19에 켜져 있었고 2026-10-20 09:38 KST에 껐다(그 뒤 새 대화·작업부터 적용). 어느 쪽이든 보내는 자료는 공개 자료뿐이다.
