# Top 3 Crypto 개인정보 처리방침

시행일: 2026-10-20

Codyssey(코디세이) 학생 팀(문수향, 공정미, 김호연, 이하 "팀")은 서비스 "Top 3 Crypto"(https://top3-crypto.vercel.app)를 운영하면서 「개인정보 보호법」 제30조에 따라 이 방침을 공개한다.

## 1. 요약

- 서비스에는 **가입, 로그인, 결제, 설문, 댓글이 없고 이름·이메일·전화번호 같은 개인정보를 받지 않는다.**
- 팀의 API 서버는 **접속 기록(IP 주소 등)을 파일이나 DB에 남기지 않도록 설정한다**(`--no-access-log`). 운영 서버에 반영한 시각은 저장소 SECURITY.md 9절에 적는다. 호스팅·연결 업체(Vercel, Tailscale, cdnjs)는 각자 정책에 따라 연결 기록을 처리할 수 있다.
- 화면 설정은 **이용자의 브라우저 안에만** 저장되고 팀 서버로 전송되지 않는다.
- AI에는 **공개 시세 수치와 공개 뉴스 제목만** 보내고 개인정보는 보내지 않는다.

## 2. 수집하는 정보, 목적, 보유 기간 (제30조 제1항 제1호·제2호)

| 정보 | 수집 방법 | 처리 목적 | 보유 기간 |
|---|---|---|---|
| 요청 횟수 계산용 접속 주소 | API 서버가 공개 요청을 받을 때 메모리에서만 셈(파일·DB에 쓰지 않음) | 과도한 요청·자동 수집 차단 | 60초 넘게 요청이 없으면 다음 정리 때 지움(최대 5,000개 유지, 서버를 다시 켜면 모두 사라짐). 60초는 횟수를 세는 창이다 |
| 오류 기록(접속 주소 없음) | API 서버의 오류 로그 | 장애 확인 | 운영 중 보관, 개인을 알아볼 정보 없음 |
| 인프라 제공업체의 연결 기록 | Vercel(호스팅), Tailscale(Funnel 연결)이 각자 정책에 따라 처리 | 서비스 전달, 보안 | 각 제공업체의 정책에 따름 |

- IP 주소는 다른 정보와 합치면 개인을 알아볼 수 있어 개인정보에 해당할 수 있다고 보고 이 방침에 적는다. 팀은 IP 주소를 파일이나 DB에 남기지 않는다. 설정을 바꾸기 전에 API 서버가 남긴 접속 기록 파일의 처리 결과도 SECURITY.md 9절에 적는다.
- 민감정보, 고유식별정보, 아동의 정보는 수집하지 않는다.

## 3. 수집하지 않는 정보

이름, 이메일, 전화번호, 주소, 계정, 결제 정보, 위치 정보, 지갑 주소, 거래소 계정과 API 키, 광고용 식별자. 서비스에는 광고와 추적(트래킹)·방문 분석 도구가 없다(화면 코드에서 확인). 글꼴은 cdnjs(Cloudflare)에서 받으므로 그 업체가 연결 기록을 처리할 수 있다.

## 4. 브라우저 저장소(localStorage)와 알림 (제30조 제1항 제7호)

1. 서비스는 이용자의 브라우저 localStorage에 다음 키를 저장한다: `top3-settings`(테마, 색, 기본 코인과 기간, 알림 켜기/끄기), `top3-chart`(차트 설정), `top3-notified`(이미 알린 트리거 목록).
2. 이 값은 **이용자 기기에만 남고 서버로 전송되지 않는다.** 서비스는 쿠키를 만들지 않는다.
3. 브라우저 알림(선택)은 브라우저의 Notification 기능으로 기기 안에서만 동작한다.
4. 이용자는 브라우저의 사이트 데이터 삭제로 언제든 지울 수 있고, 알림은 브라우저 설정에서 끌 수 있다.

## 5. 제3자 제공과 처리 위탁 (제30조 제1항 제3호·제4호)

1. 팀은 개인정보를 제3자에게 판매하거나 제공하지 않는다.
2. 서비스 제공을 위해 다음 업체가 인프라를 운영하며, 접속 기록은 각 업체의 정책에 따라 처리될 수 있다.

| 업체 | 역할 | 정책 |
|---|---|---|
| Vercel Inc. | 정적 웹사이트 호스팅, `/api/*` 요청 전달 | https://vercel.com/legal/privacy-policy |
| Tailscale Inc. | Funnel로 팀 컴퓨터 API를 안전하게 연결 | https://tailscale.com/privacy-policy |
| Cloudflare(cdnjs) | 화면 글꼴(Pretendard) 파일 전송 | https://www.cloudflare.com/privacypolicy/ |

3. 국외 이전: 위 업체는 미국 등 해외 서버를 쓸 수 있다. 업체가 처리하는 정보는 연결 기록(IP 주소, 요청 시각 등)에 한정되며, 이전 국가·보관 기간은 각 업체 정책을 따른다.

## 6. AI 서비스 이용과 개인정보

1. 팀 컴퓨터의 예약 작업이 **공개 시세 수치와 GDELT 뉴스 제목**을 OpenAI(GPT)에 보내고, 실패하면 Anthropic(Claude)에 보낸다. 이용자의 접속 정보와 브라우저 설정은 보내지 않는다.
2. 따라서 이용자의 개인정보가 AI 업체로 이전되지 않는다. 자세한 내용은 [AI 이용 고지](ai-notice.md)를 본다.

## 7. 알프레도(Alfredo) 로컬 시제품 안내

알프레도는 같은 팀원이 만든 별도의 모의투자 시제품이다. 개발자 컴퓨터의 `127.0.0.1`(자기 컴퓨터 안)에서만 실행되고 인터넷에 공개되지 않는다. 이 시제품의 채팅은 입력한 질문과 화면의 가상(합성) 숫자를 OpenAI(GPT)에 보내며, 대화는 저장하지 않고 서버 로그에도 질문 내용을 남기지 않는다. 화면 경고대로 **개인정보, 계좌, 금액은 입력하지 않아야 한다.** 이 시제품은 Top 3 Crypto 공개 서비스에 포함되지 않는다.

## 8. 파기 절차와 방법 (제30조 제1항 제3호의2)

팀은 접속 기록을 남기지 않으므로 새로 파기할 접속 기록이 없다. 요청 횟수 계산용 접속 주소는 60초 넘게 요청이 없으면 다음 정리 때 메모리에서 지우고, 서버를 다시 켜면 모두 사라진다.

## 9. 정보주체의 권리와 행사 방법 (제30조 제1항 제5호)

이용자는 자신의 개인정보에 대해 열람, 정정·삭제, 처리정지를 요구할 수 있다. 팀은 접속 기록을 보관하지 않아 열람할 개인정보가 없는 것이 보통이다. 요구는 아래 문의 창구로 하며 팀은 10일 이내에 답한다. 만 14세 미만 아동의 정보는 수집하지 않는다.

## 10. 개인정보 보호책임자와 문의 (제30조 제1항 제6호)

- 개인정보 문의 담당(초안): 김호연(서비스 개발·운영 담당). 공식 책임자 지정은 공개 전 팀 확인이 필요하다.
- 문의: GitHub Issues https://github.com/kimble125/top3-crypto-final/issues (공개 글에는 개인정보를 쓰지 말 것. 개인정보가 담긴 요청은 제목에 '비공개 연락 요청'이라고만 남기면 책임자가 연락 방법을 안내한다)
- 침해 신고·상담: 개인정보침해 신고센터(privacy.kisa.or.kr, 국번 없이 118), 개인정보분쟁조정위원회(www.kopico.go.kr, 1833-6972)

## 11. 방침의 변경

방침을 바꿀 때는 시행일 7일 전에 저장소와 서비스 화면에 알린다. 변경 이력은 저장소 커밋 기록으로 남는다.
