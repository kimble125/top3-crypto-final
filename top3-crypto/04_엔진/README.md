# 04_엔진 — 지표·확신도·매매 트리거·AI 분석·알림 (공개용 설명)

> 공개 제출본의 엔진 설명입니다. 운영 조건의 상세 설명, 팀 내부 의사결정 기록, 채점 기준 값, 과거 재현 성적은 팀 결정(2026-10-13, 공개 범위)에 따라 넣지 않았습니다. 이 사본의 채점 기준 값은 시험용 예시입니다.

## 하는 일

| 주기 | 하는 일 | 파일 |
|---|---|---|
| 15분마다 | 수집기가 캔들을 넣은 뒤 엔진 사이클을 부른다. 지표 계산, 15분 기술 조건(Core Condition) 상태, 확신도 계산 | `run_cycle.py`, `indicators.py`, `judge.py`, `strong15.py`, `confidence.py` |
| 15분마다 | 기술 조건 사건 + 그 순간 AI 추세 방향이 같을 때 공식 매매 트리거를 만들고 디스코드로 알림 | `trigger.py`, `notify.py` |
| 하루 2번(09·21시 KST)과 조건이 켜질 때 | 6개 항목 AI 분석(전략·확신·뉴스·공포탐욕·시장 흐름·기술 분석)을 만들고 코드가 검사 | `ai_analysis.py`, `guard.py` |
| 손으로 | 같은 규칙을 과거 자료에 적용하는 재현(결과는 `reports/`) | `replay.py`, `trigger.py --replay`, `confidence_replay.py` |

## 확신도

신호 8개를 두 묶음으로 나눕니다. 기술 지표(가격 위치·MACD 4시간·Stochastic 1시간·StochRSI 1시간)와 시장 자료(미결제약정·코인베이스 프리미엄·공포탐욕지수·뉴스 방향)에 묶음 안 가중치 8·7·6·5를 주고, 신호마다 Long +1·Short −1(약해지면 ±0.5)을 곱해 묶음 점수(−100–+100)를 냅니다. 두 묶음 점수의 평균 D로 확신도 = 50 + 0.4 × D(10–90%)를 계산합니다. AI를 부르지 않고 15분마다 계산하며, 계산식이 화면 '근거' 카드에 그대로 나옵니다. 과거 성적으로 맞춘 확률이 아닙니다.

## AI 분석의 안전장치

- 입력: 공개 시세 수치와 GDELT 뉴스 제목. 네이버 뉴스 검색결과는 네이버 검색 API 약관(2026-09-07 시행 특약 2.3)에 따라 AI에 보내지 않습니다(`AI_NEWS_EXCLUDE`).
- 뉴스 제목 안의 지시문은 AI에 보내기 전에 거릅니다(`guard.is_injection`).
- 출력 검사(`validate`): 권유 표현, 입력에 없는 숫자, 현재가 ±30% 밖 추정, 프롬프트 구조 문구가 있으면 버립니다.
- GPT(Codex CLI)가 실패하면 Claude(Claude Code CLI)로 한 번 대신 분석합니다. 비밀값 환경 변수는 넘기지 않습니다.

## 설정 (`conf/`)

| 파일 | 내용 |
|---|---|
| `rules_v3.json` | 지표 파라미터와 판정 방식. 공개본은 내부 메모를 지웠고, 문턱·가중치 일부도 예시화했으므로 규칙 버전 해시는 운영과 다릅니다 |
| `trigger.json` | 트리거·채점 설정. 공개본의 채점 기준(`success_pct`)은 예시 값입니다 |
| `strong15.json`, `engine.json` | 15분 조건 상태 기록, 사이클 설정 |
| `explain.json` | AI 호출 설정(모델, 시간 제한, 금지 표현) |
| `discord.json` | 디스코드 전달. 공개본은 `dry_run`(보내지 않고 기록만) |

프롬프트(`prompts/`)는 공개용 뼈대입니다. 운영 프롬프트 원문은 넣지 않았습니다.
